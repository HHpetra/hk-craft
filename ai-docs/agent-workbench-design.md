# Agent Workbench（Agent 专属三位一体工作台）设计方案

## 一、 核心架构与技术选型

- **客户端架构**：**Tauri v2** + **Rust 后端** + **React 前端**
- **终端引擎**：前端 `xterm.js` + WebGL 渲染插件；后端使用 Rust `portable-pty` 实现跨平台原生 PTY 会话常驻与全天候保活（切 Tab/切视图不中断进程与输出）。
- **配置与持久化**：采用 **本地单文件 TOML 配置**（如 `~/.agent-workbench/config.toml`），管理项目列表、Agent 预设模板、常用外部书签及分屏比例偏好。
- **布局引擎**：`react-resizable-panels` 支持丝滑的自由分屏比例调整，并支持本地记忆。

## 三、 核心模块功能定义

### 1. 📂 文件资源管理器（独立一级面板）
- **左侧书签栏**：当前项目根目录、全局常用共享目录（如公共工具库、配置文件夹），一键切换浏览目标。
- **右侧主文件区**：
  - 类似主流文件管理器的**详细列表模式**（名称、修改日期、类型、大小）与**图标平铺模式**。
  - 支持路径面包屑导航、快速搜索过滤、文件名排序。
- **拖拽注入（Drag-to-Inject）**：
  - 选中内部文件列表中的任意文件/文件夹，直接拖入 Agent 终端，自动格式化并带上前缀（例如 `@C:\path\to\file.ts`）。
  - 拖入 Runner 终端，自动格式化为标准双引号绝对路径（`"C:\path\to\file.ts"`）。

### 2. 🤖 Agent 终端 & ⚡ Runner 终端
- **Agent 终端**：绑定当前项目的 Agent 预设模板（如 `cursor-agent` / `opencode` / `claude` / `dsh-tui`），项目激活时自动拉起。
- **Runner 终端**：纯净的工作目录 Shell（PowerShell / CMD / Bash），用于常规程序运行与调试。
- **状态感知**：监听终端静默与退出状态，在 Tab 与按钮上显示状态指示灯；后台长时间任务完成时触发系统 Toast 提醒。

### 3. 📑 多项目与配置中心
- **左侧项目列表栏**：直观展示所有纳管项目、当前激活项及后台运行状态角标，支持一键切换项目上下文，每个项目拥有独立的 Trinity（资源管理 + 双终端）状态。
- **配置结构（`config.toml` 示例）**：
  ```toml
  [settings]
  theme = "dark"
  default_split_ratio = [30, 40, 30]

  [[agent_presets]]
  id = "cursor-agent"
  name = "Cursor Agent"
  command = "cursor-agent"
  drag_prefix = "@"

  [[agent_presets]]
  id = "opencode"
  name = "OpenCode"
  command = "opencode"
  drag_prefix = "@"

  [[bookmarks]]
  name = "共享组件库"
  path = "C:/Workspace/SharedLib"

  [[projects]]
  name = "Agent10-WorkTable"
  path = "C:/Agent/Agent10-WorkTable"
  agent_preset = "cursor-agent"
  ```

## 四、 第一期开发路线（Phase 1 MVP）

1. **项目骨架搭建**：初始化 Tauri v2 + Rust + React + Tailwind + Lucide 项目。
2. **Rust PTY 与终端打通**：实现基于 `portable-pty` 的 PTY 管理器，前端通过 `xterm.js` 渲染。
3. **三位一体布局与视图切换**：集成 `react-resizable-panels`，实现单焦全屏（Ctrl+1/2/3）与平铺分屏（Ctrl+4）即时切换。
4. **内置文件管理器与拖拽**：实现 Rust 文件系统读取接口、详细列表视图与拖拽插入路径功能。
5. **左侧多项目列表与 TOML 配置持久化**：实现左侧项目增删切换、Agent 模板选择与状态保存。
