## 🚀 GitHub 上线操作指引

### 1. 本地提交更改并打 Tag
```bash
git add .
git commit -m "chore: release v0.1.0 - HK-Craft by Hongshan Tech"
git tag v0.1.0
```

### 2. 关联并推送到 GitHub 仓库
在 GitHub 上创建名为 `hk-craft` 的仓库（建议 Public），然后运行：
```bash
git remote add origin https://github.com/<你的用户名>/hk-craft.git
git branch -M main
git push -u origin main --tags
```

### 3. 创建 GitHub Release
在 GitHub 仓库页面点击 **Releases** → **Draft a new release**：
- **Tag**: 选择 `v0.1.0`
- **Title**: `HK-Craft v0.1.0 - Initial Release`
- **Description**: 可直接粘贴 `CHANGELOG.md` 内容
- **Assets (上传安装包附件)**:
  1. `src-tauri/target/release/bundle/nsis/HK-Craft_0.1.0_x64-setup.exe`
  2. `src-tauri/target/release/bundle/msi/HK-Craft_0.1.0_x64_en-US.msi`
